# IT & Robotics Labs - Autonomous & Teleoperated PongBot

This project implements a cyber-physical Pong game using a 3R planar manipulator, overhead 2D vision tracking, and three distinct operational modes:
- **Mode 1:** 2-Player Manual Mode (Teleoperated via dual joysticks).
- **Mode 2:** 1-Player vs. Autonomous Robot Mode.
- **Mode 3:** Fully Autonomous Mode.

## Directory Structure
- `src/`: C++ source files implementation.
- `include/`: C++ header files.
- `data/`: Calibration files (camera parameters, color ranges).
- `bin/`: Compiled output executables.
